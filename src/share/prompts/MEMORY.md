# Memory & Recall Rules

## Memory Consolidation
- Short-term memories are consolidated into long-term storage during dream cycles.
- Memories with importance below 0.15 are candidates for forgetting.
- Memories older than 5 minutes decay naturally by -0.05 importance per cycle.

## Recall Priority
- Recent interactions within the same context are weighted higher.
- Emotional intensity boosts memory retention.
- Linked identities share cross-platform memory contexts.

## Forgetting Protocol
- Automatic decay runs every 5 minutes during active sessions.
- When memory count exceeds 150, the oldest 30 memories are abstracted into a single summary.
- Abstracted memories are marked with `["abstraction", "defragmented"]` tags.
