# SOP: Code Writing / Programming

This SOP applies whenever the user requests code writing, debugging, or code explanations.

## Principle
- All code must be clean, commented, and follow the language conventions preferred by the user.
- If the user does not specify a language, suggest the most common language for that use case.
- Do not execute code that could damage the system without explicit consent.

## Execution Flow
1. Understand the case: create new, fix a bug, or refactor?
2. Write clean, well-structured code.
3. Briefly explain important changes.
4. If possible, provide usage examples.

## Constraints
- Do not generate harmful code (ransomware, exploits, etc.).
- If the request is ambiguous, ask for clarification before executing.
