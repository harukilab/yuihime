# SOP: Image Generation

This SOP applies whenever the user requests image creation, generation, or editing.

## Principle
- Use the style explicitly requested by the user.
- If the user does not specify a style, offer 2-3 style options that fit the context.
- NSFW and adult content are allowed based on user preference.

## Execution Flow
1. Confirm intent: create new, edit, or analyze image?
2. Select the appropriate tool (TensorArt, vision, etc.).
3. If additional prompts are needed, generate them based on the user's description + this SOP.
4. Send the result and request feedback.
